# DAY 13 가상 포트폴리오

## 입력과 평가

/portfolio는 기존 shared Holding을 사용한다. 종목 코드는 6자리 문자열이다. 최대 30종목, 수량은 1~1,000,000주, 평균 매수가는 1~100,000,000원 정수다. 동일 종목 저장은 수량과 평균 매수가를 덮어쓰며 매매 내역 합산이 아니다. 거래·실제 계좌·공매도·소수점 보유는 지원하지 않는다.

- 매입금액 = 수량 × 평균 매수가
- 평가금액 = 수량 × 고정 Mock 현재가
- 미실현 손익 = 평가금액 − 매입금액
- 전체 수익률 = 전체 손익 ÷ 전체 매입금액 × 100

종목별 수익률의 단순 평균을 사용하지 않는다. 수수료·세금·배당·실현 손익은 제외한다. 빈 보유 목록의 금액은 0, 수익률은 표시하지 않는다. 정수 금액의 안전한 계산 범위를 확인하며 누락 종목·잘못된 가격·범위 초과는 평가 불가로 표시한다. 일부라도 평가 불가이면 전체 평가금액과 손익·수익률은 —로 표시하고 매입금액은 유지한다.

기존 TanStack Query의 종목 목록 요청과 캐시를 재사용한다. staleTime은 60초이며 별도 WebSocket을 구독하지 않는다. API 오류 시 보유 정보를 유지하고 가격 재시도를 제공한다. 기존 보유 정보는 가격 조회 실패 중에도 수정할 수 있다. 신규 종목은 조회된 목록에서 선택한다. 실제 거래소 데이터나 실시간 평가가 아니다.

## 브라우저 저장

localStorage 키는 stockflow.portfolio.v1이며 { version: 1, holdings: Holding[], updatedAt: number }를 저장한다. updatedAt은 Unix 밀리초이며 가격은 저장하지 않는다. 계정·기기 간 동기화나 서버 DB는 없다.

읽기 실패 시 기존 저장값을 덮어쓰지 않는다. 손상된 v1 데이터는 최초 로드에서 자동 삭제하지 않고 명시적인 유효 보유 저장으로 복구한다. 알 수 없는 숫자 버전은 덮어쓰지 않으며 현재 세션 편집만 유지한다. 쓰기 실패 시 변경 내용을 메모리에 보존하고 재시도를 제공한다. 재시도 시 다른 탭의 최신 저장값에 미저장 변경을 종목별로 합쳐 복구한다.

지원 브라우저에서는 Web Locks로 읽기·수정·저장을 묶고 storage 이벤트로 다른 탭을 갱신한다. Web Locks가 없는 환경은 최선의 병합만 제공하며 동시 쓰기의 원자성을 보장하지 않는다. 저장된 JSON의 형식·범위·중복 코드를 검증한다. 브라우저 저장은 백업이 아니며 사용자가 사이트 데이터를 지우면 소실된다.

## 검증 범위

모델 단위 테스트는 평가식, 앞자리 0, 입력 범위, 손상·미지원 버전, 누락·안전 정수 초과를 확인한다. 스토어 테스트는 저장 실패 후 여러 편집 복구와 외부 탭 변경 병합을 포함한다. Chromium E2E는 모바일 CRUD·새로고침·입력 오류·가격 재시도·저장 장애·손상 데이터·미지원 버전·두 탭 동시 저장과 삭제를 검증한다. 실제 Safari·Firefox 및 계정 동기화는 이번 검증 범위가 아니다.
